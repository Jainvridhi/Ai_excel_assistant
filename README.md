> **Talk to your Excel file in plain English. Upload a spreadsheet, ask questions, and get instant data analysis — no formulas needed.**

## ❓ Problem Statement
Most business users struggle with Excel formulas, pivot tables, and data analysis. This app lets anyone — regardless of technical skill — ask questions about their data in natural language.

## 💥 Impact
- **Zero Excel skills needed** — just type your question
- Ask: *"What's the total revenue by region?"* → get instant answer
- Works on any uploaded `.xlsx` or `.csv` file

## 🛠️ Tech Stack
`Python` · `Pandas` · `LLM API` · `Streamlit` · `OpenPyXL`
